## When to Use

The user requested the creation of a text file with a specific name.

## Procedure

1. Identify the request for file creation.
2. Call the appropriate file writing tool.
3. Provide the desired filename as an argument.
4. Confirm successful file creation.

Use the write_file tool followed by the desired filename to create the specified file.
