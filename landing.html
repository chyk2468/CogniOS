◆ Overview

One AI Workspace.
Everything You Need.

CogniosAI replaces scattered tools with a single self-hosted workspace. Chat with AI agents, manage email, edit documents, run research, serve local models — all from one interface.

🤖

Chat + Agents

Full agent mode with 40+ tools — shell, Python, file ops, web search, email, calendar, memory, skills, and MCP. Works with local and API models.

📖

Cookbook

Hardware-aware model recommendations, one-click downloads from HuggingFace, and model serving via vLLM, SGLang, llama.cpp, or Ollama. GPU auto-detection built in.

🔬

Deep Research

IterResearch-style multi-step engine: Think → Search → Extract → Synthesize. The LLM drives every decision — what to search, what's relevant, and when to stop.

📧

Email Client

Full IMAP/SMTP inbox with AI triage, tags, summaries, reminders, reply drafts, bulk operations, and multi-account support. No external email service needed.

📝

Documents + Notes

Writing-first editor with AI suggestions, Markdown, HTML, CSV, and syntax highlighting. Google Keep-style notes with checklists, reminders, labels, and pinning.

📅

Calendar + Tasks

CalDAV sync, event scheduling with recurrence rules, importance levels, event types, and AI-scheduled automated tasks with cron-like triggers.

⚖️

Compare

Blind side-by-side model comparison. Test multiple models on the same prompt, see which one performs better, and synthesize the best answer.

🖼️

Gallery + Image Editor

AI image generation with Stable Diffusion. Built-in upscale, background removal, inpainting, and harmonization tools. Full gallery management.

🧠

Memory + RAG

Persistent memory across sessions — facts, events, contacts, preferences. ChromaDB-powered vector search with RAG for your private knowledge base.

◆ Deployment

Deploy Anywhere

Docker, native Python, or bare metal. Windows, Linux, macOS. Single machine or multi-node.

🐳

Docker (Recommended)

docker compose up -d --build. GPU passthrough, auto-setup, healthchecks.

🐧

Linux Native

Python + pip. Full CUDA and ROCm support. Systemd service included.

🪟

Windows

PowerShell launcher with venv auto-setup. WSL optional for GPU serving.

🍎

macOS

Universal build script. Apple Silicon with Metal acceleration for llama.cpp.

🏢

LAN / Enterprise

Multi-user with auth, 2FA, RBAC. Reverse proxy with Tailscale or VPN.

☁️

Private Cloud

Your VMs, your rules. Configure remote GPU servers via Cookbook SSH.
